Visual Studio und git einrichten

Diese Seite erläutert die Schritte zum Einrichten Ihres Arbeitsplatzes. Sie benötigen den Text-Editor Visual Studio Code und das Versionskontrollsystem git.

GitHub-Account erstellen

  • Sollten Sie noch keinen haben, legen Sie einen GitHub-Account an.
  • Tragen Sie sich und Ihren Account-Namen in diese Google-Tabelle ein.
  • Für Studierende stellt GitHub kostenlose Professional-Accounts bereit. Mit diesen können Sie private Repositorys und GitHub Copilot nutzen. Besuchen Sie GitHub Education und beantragen Sie Ihren Account.

Visual Studio Code installieren

Falls noch nicht gesehen, Installieren Sie

  • Visual Studio Code.
  • die Extension Git Graph.
  • die Extension Live Server.
  • die Extension W3C Web Validator.

Git installieren

Windows

  • Installieren Sie git.
  • Öffnen Sie die git-Bash und setzen Sie Ihren Namen mittels folgendem Befehl (ACHTUNG: meinname mit Ihrem Namen austauschen): git config --global user.name "meinname"
  • Setzen Sie Ihre Mail-Adresse mittels folgendem Befehl (ACHTUNG: mymail@gmail.com mit Ihrer Mail-Adresse austauschen): git config --global user.email "mymail@gmail.com"

macOS

  • Installieren Sie homebrew mittels folgendem Befehl im Terminal (Programme -> Dienstprogramme):
    /bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
  • Nun können Sie git im Terminal installieren: brew install git
  • Setzen Sie Ihren Namen mittels folgendem Befehl (ACHTUNG: meinname mit Ihrem Namen austauschen): git config --global user.name "meinname"
  • Setzen Sie Ihre Mail-Adresse mittels folgendem Befehl (ACHTUNG: mymail@gmail.com mit Ihrer Mail-Adresse austauschen): git config --global user.email "mymail@gmail.com"
