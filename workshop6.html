Technologie und Produktion Workshop 6: TouchDesigner – Einführung


Abgabe: Mittwoch, 15. Juli 2026 – Ordner als ZIP-Datei vorname_nachname_workshop6.zip auf Stud.IP.

In den Workshops 6 und 7 arbeiten Sie mit TouchDesigner – einer node-basierten visuellen Programmierumgebung für Echtzeit-Visualisierungen, die vor allem in der Medienkunst und bei Live-Events eingesetzt wird.

Im heutigen Workshop 6 lernen Sie die Oberfläche kennen und bauen zwei geführte Tutorials nach, die Sie mit eigenen Assets individualisieren. In Workshop 7 erstellen Sie dann eine Videoprojektion mit KantanMapper.

TouchDesigner installieren

  • Laden Sie TouchDesigner unter derivative.ca/download herunter (kostenlose Non-Commercial-Lizenz genügt).
  • Erstellen Sie ein kostenloses Konto auf derivative.ca, um die Software freizuschalten.

TouchDesigner arbeitet mit einem node-basierten Netzwerk: Operatoren (OPs) werden miteinander verbunden und verarbeiten Daten in Echtzeit. Doppelklick in das Netzwerk öffnet den Operator-Dialog, Tab öffnet die Suchmaske.

Aufgabe 1: Interaktiver Partikelregen mit Optical Flow & ParticlesGpu

In diesem Tutorial erstellen Sie einen GPU-beschleunigten Partikelregen, der auf Bewegungen vor einer Webcam reagiert. Die Kamerabewegungen werden mit dem Operator Optical Flow extrahiert und steuern in Echtzeit einen ParticlesGpu-Effekt.

Öffnen Sie das Video-Tutorial und bauen Sie die Schritte in TouchDesigner nach:

Individualisierung

Nachdem Sie das Tutorial nachgebaut haben, passen Sie Ihr Projekt mit folgenden Anpassungen an Ihren eigenen Geschmack an:

Custom Texture

Nutzen Sie statt den Preset-Texturen eine eigene Bild- oder Videodatei für Ihren Partikelregen. Vielleicht haben Sie auch im Workshop mit Herrn Posavec bereits eigene 3D-Modelle oder Texturen genutzt, die Sie hier wieder einsetzen möchten. Stellen Sie dazu unter Material → Texture die Option Custom ein und hinterlegen Sie Ihre Datei.

Parameter anpassen

Passen Sie mindestens drei der folgenden Parameter nach Ihrem individuellen Geschmack im Parameter-Fenster unter ParticlesGPU bzw. Forces an :

Parameter Wirkung Bedeutung
Birth Anzahl neuer Partikel pro Frame „Mehr oder weniger Regen"
Life Min Lebensdauer der Partikel „Partikel verschwinden schneller/langsamer"
Particle Size Min & Max Größe der Partikel „Kleine vs. große Tropfen"
Speed Gesamte Simulationsgeschwindigkeit „Zeitlupe ↔ Turbo"
Optical Flow Magnitude Reaktion auf Bewegung „Wie stark wirkt die Hand- und Kopfbewegung"

Speichern Sie Ihr Ergebnis als partikelregen.toe. Legen Sie die verwendete Bild-/Videodatei in denselben Ordner, damit TouchDesigner sie über den relativen Pfad finden kann. Bitte überprüfen Sie beim moviefilein mit ihrer Bild-/Videodatei, dass der Pfad im Parameter-Fenster unter "Play" -> "File" als relativer Pfad auf die Bild-/Videodatei angelegt ist.

Individualisierung

Tauschen Sie die beiden Beispielbilder gegen eigene Fotos aus dem Fotoworkshop aus. Fügen Sie darüber hinaus ein drittes Bild hinzu, so dass die Anwendung durch drei Bilder bei Touch cycelt. Dafür können Sie beispielsweise den Switch-Operator statt des Cross-Operators verwenden.

Fotos Austauschen durch Vorbereitung in Photoshop

Passen Sie Ihre Fotos vorab in Photoshop an:

  • Bildgröße: 1024 × 1024 px
  • Auflösung: 72 dpi
  • Format: .jpg

Bilder in TouchDesigner importieren

Fügen Sie für jedes Bild einen TOP Movie File In-Operator ein. Im Parameterfenster bei File auf + klicken und das vorbereitete Bild auswählen.

Speichern Sie die fertige Datei als image-switcher.toe und legen Sie beide Bilddateien in denselben Ordner.

Infos zur Abgabe

Legen Sie beide .toe-Dateien sowie alle verwendeten Bild-/Videodateien in einen Ordner. Achten Sie darauf, dass TouchDesigner auf die Assets über relative Pfade aus dem Ordner heraus zugreifen kann.

Laden Sie den Ordner als ZIP-Datei auf Stud.IP hoch:

Erwartete Ergebnisse

Minimum: Beide Tutorials sind nachgebaut und als .toe-Dateien abgegeben.

Gut: Eigene Assets (Custom Texture, eigene Bilder) sind eingebunden und die Parameter wurden individuell angepasst.

Sehr gut: Die Individualisierung geht über einfaches Asset-Austauschen hinaus – die Szene hat einen eigenen visuellen Charakter und die Parameteranpassungen wirken bewusst gestalterisch eingesetzt.
