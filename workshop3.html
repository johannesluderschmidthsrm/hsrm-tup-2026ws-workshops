Hinweis: Tauschen Sie in den unten stehenden Beispielen[css selektor] so aus, dass Elemente auf der Seite verwendet werden. Ergänzen Sie an den Elementen ggf. class oder id-Attribute.

Ereignisse verarbeiten

Mit folgendem Code können Sie eine Funktion für einen Klick auf Element(e) registrieren.

$('[css selektor]').click( function (e) {
    console.log('Folgendes Ereignis ist aufgetreten: ', e);
});

Die Variable e in der Ereignisverarbeitungsfunktion enthält das ausgelöste Ereignis. Schauen Sie sich in der Konsole an welche Eigenschaften und Methoden dieses hat.

Die für uns wichtigste Methode heißt preventDefault. Wenn man sie aufruft, verhindert man, dass die dem Event zugeordnete  Standard-Aktion (z.B. ein Seitenwechsel bei einem Link) ausgeführt wird.

Klassen setzen

Am effektivsten lässt sich das Aussehen von Elementen mit JavaScript steuern, wenn man nur Klassen hinzufügt oder entfernt und das Aussehen und die Animationen allein in CSS definiert:

// Klassen hinzufügen
$('[css selektor]').addClass('meine-klasse'); 

// Klassen entfernen
$('[css selektor]').removeClass('meine-klasse');

Mit Hilfe der toggle-Funktion kann man einfach einen Klassennamen abwechselnd hinzufügen oder entfernen ohne vorher überprüfen zu müssen, um welchen Zustand es gerade geht.

// Klassen wechseln
$('[css selektor]').toggleClass('meine-klasse');

Ein- und Ausblenden

Sie können Elemente direkt mit jQuery ein und ausblenden und sogar löschen.

$('[css selektor]').hide(); // Setzt Element auf diplay:none;
$('[css selektor]').show(); // Entfernt display:none;
$('[css selektor]').toggle(); // Wechselt zwischem beidem
$('[css selektor]').remove(); // Löscht das oder die Elemente

Eleganter ist es aber, in CSS eine Klasse zu definieren und diese dann zu setzen:

.hidden {
    display:none!important; /* Ja, hier macht !important Sinn */
}                        

$('[css selektor]').addClass('hidden'); // Setzt die Klasse

CSS-Eigenschaften ändern

Mit JavaScript kann man auch direkt CSS-Eigenschaften ändern. Auch z.B. bei allen Artikeln. 

$('article').css('color', 'red');
$('article').css('padding', '50px');

// Alternative Schreibweise mit Objektliteral
$('article').css({
    'color': 'red',
    'padding': '50px'
});

Überprüfen Sie mit den Browser-Developer-Tools das jeweilige Element (Rechtsklick: “Element untersuchen”) und schauen Sie sich an, wo dieses CSS auftaucht.

Aufgabe 2b:Einfacher Klapper

Vielleicht kennen Sie den Effekt, dass bestimmte Abschnitte einer Seite zugeklappt sind und sich erst dann öffnen, wenn man auf die Überschrift klickt. Dieses sog. “Klapper” bzw. “Accordion”-Funktionalität lässt sich vergleichsweise einfach selbst mit etwas CSS und JavaScript realisieren.

  1. Fügen Sie den article -Abschnitten eine Klasse klapper hinzu.
  2. Ergänzen Sie Ihr JavaScript so, dass es beim Klick auf eine Überschrift innerhalb dieser Elemente im darüber liegenden .klapper die Klasse  open ergänzt/entfernt. Nutzen Sie dabei die jQuery-Funktion um die übergeordneten Element zu erreichen:
$('.klapper h2').click(function(){
    $(this).parents('.klapper').toggleClass('open');
});
  1. Ergänzen Sie ihr CSS so, dass mit Ausnahme der Überschrift die Inhalte des .klapper-Artikels dann ausgeblendet werden, wenn dieser nicht die Klasse  open hat. Verwenden Sie hierzu die Pseudoklasse :not() : 
.klapper:not(.open)>:not(h2){
    display: none;
}
  1. Fügen Sie mit CSS vor oder hinter der Überschrift Element (Z.B. ein Symbol) ein, das anzeigt ob der Klapper offen oder geschlossen ist. Verwenden Sie hierfür die Pseudoklasse ::before .

Aufgabe 3: Animiert zu Bereichen in der Seite scrollen

Sicherlich kennen Sie den Effekt auf One-Page-Seiten, mit dessen Hilfe Sie durch Klicken auf Elemente in der Navigation zu bestimmten Bereichen der Seite animiert scrollen. Diesen Effekt können Sie relativ einfach mit jQuery umsetzen.

Normalerweise werden Sprünge in der Seite mit Anker-Links umgesetzt. D. h. dass an einem Element eine bestimmtes id-Attribut gesetzt wird und von einem anderen Link-Element darauf verwiesen wird:

<article id="springHierher">…</article>
<a href="#springHierher">Springe Hierher</a>

Beim Klicken des Links springt die Seite aber ruckartig zu dem Ziel in der Seite. Das wollen wir verbessern.

  1. Fügen Sie einen weiteren article an das Ende von workshop3.html an. Vergeben Sie ein id-Attribut Ihrer Wahl an diesem Element.
  2. Betten Sie in diese article einen Social-Media-Post ein. Das geht beispielsweise gut mit X-Posts. Informieren Sie sich online, wie das funktioniert.
  3. Fügen Sie einen Link in Ihre Navigation ein, der einen Anker-Link auf den neuen article bereitstellt. Testen Sie, ob der Link funktioniert (noch ohne animiertes Scrollen).
  4. Erweitern Sie Ihren JavaScript-Code um folgende Elemente. Registrieren Sie für alle a-Elemente, deren href-Attribut eine # enthält, mit einem Click-Listener.
  5. In diesem Listener soll detektiert werden, ob es ein Element mit dem im Anker definierten Link gibt.
  6. Wenn das so ist, dann soll mit der jQuery-Funktion animate zur Position diese Ziels gescrollt werden. Das erreichen Sie mit folgendem Code (Sie finden Ihn auch unter js-workshop/example-code.js).
$('a[href*="#"]').click(function (e) {

    // Sprungziel ermitteln  
    var href = $(this).attr('href'),
        $scrollAim = $(href);

    // Abbrechen wenn kein Sprungziel gefunden    	 
    if ($scrollAim.length == 0) return;

    // Automatisches Scrollen verhindern
    e.preventDefault();

    // Zum Sprungziel animieren
    $('html,body').animate({
                scrollTop: $scrollAim.offset().top
    }, 700);
});

Aufgabe 4: Bildergalerie mit Lightbox-Funktion

Bildergalerien, die bei Klick auf eine Vorschau ein größeres Bild öffnen, findet man auf fast jeder Website. Wir wollen eine solche nun einmal mit reinen Bordmitteln (also reinem CSS/JS) realisieren.

Die Bildergalerie

  1. Erstellen Sie in einem der Artikel eine Bilder-Galerie, die mehrere Bilder als Thumbnails anzeigt. Verwenden Sie hierzu eine List <ul> mit einem <li> für jedes Bild. Um Bandbreite zu sparen, fügen Sie die Bilder nicht im Originalformat ein, sondern nur als kleingerechneten Thumbs von wenigen hundert Pixeln Breite. Es ist Ihre Aufgabe, die Thumbnails in einem Bildbearbeitungs-Programm Ihrer Wahl zu erzeugen.
<ul class="image-gallery">
	<li>
        <img src="../_assets/images/blossoms.jpg">
        <div>Irgendeine Beschreibung</div>
	</li>
	...
</ul>
  1. Schauen Sie sich in der CSS-Datei an, wie das Aussehen der Galerie realisiert wurde und passen Sie dieses nach Ihrem Geschmack an.
  1. Sorgen Sie dafür, dass die Bilder in der mobilen Ansicht untereinander stehen.
  1. Um bei Klick auf eine Thumbnail eine Großansicht zu öffnen, umgeben Sie nun den Inhalt jedes Links mit einem<a href="...">, und geben dort das Große Bild als Linkziel an. Ergänzen Sie das Attributtarget, um die Bilder in einem neuen Tab zu öffnen.

Die Lightbox

Nun wollen wir dafür sorgen, dass die großen Bilder nicht einfach in einem neuen Tab geöffnet werden, sondern in der selben Seiten – in einem HTML-Element, dass sich über alle drüber legt.

  1. Hierfür markieren Sie zunächst alle Links, die diese Funktionalität haben sollen mit der Klasse lightbox-link.
  1. Nun erstellen Sie eine JavaScript-Funktion, die bei Klick auf einen solchen Link neues HTML mit dem großen Bild in die Seite hinzufügt. Verwenden Sie hierfür den Event-Handler click. und verhindern Sie das Ausführen des Links mit der Funktion, die Sie oben bereits kennengelernt haben. Der weiter JS-Code gehört dann dahinein.
$('a.lightbox-link').click(function(e){
    e.preventDefault();
    // Hier kommt der Code hin
});
  1. Nun erzeugen Sie mit jQuery ein neues HTML-Element mit der korrekten Bild-URL:
var $html = $('<section class="lightbox"><button class="btn-close">Bild Schließen</button><figure><img src="' + this.href + '"><figcaption>Ihr großes Bild</figcaption></figure></section>');
  1. Dieses HTML-Element fügen Sie nun mit der append-Funktion vor dem schließenden body-Tag ein. 
$('body').append( $html );
  1. Es ist Ihre Aufgabe, dieses HTML per CSS so zu stylen, dass es groß über allen anderen Inhalten liegt. Verwenden Sie dazu die CSS-Eigenschaft postition:fixed; und stylen Sie dann die Elemente, so dass sie die gesamten Bildschirm ausfüllen und das BIld entsprechend skaliert wird.
  1. Nun sollten Sie noch einen neuen Click-Handler auf die den Schließen-Button legen, um das große Bild wieder entfernen zu können. Hierfür suchen sie in $html mit der jQuery-Funktion find den Button. find() erwartet dabei dieselbe Art von Selektoren wie $().
$html.find('.btn-close').click(function(e){
