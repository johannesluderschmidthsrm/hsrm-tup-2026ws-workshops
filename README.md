# hsrm-tup-2026ws-workshops

Übungsverzeichnis für den MM-Kurs **Technologie und Produktion (IM/UI)**.

Die Daten werden automatisch auf den TestServer deployed und können dort gestestet werden.

Bitte legen Sie sich für Ihre Übungsaufgaben einen Ordner <code>vorname-nachname/</code> (keine Großbuchstaben oder Sonderzeichen) an und arbeiten Sie ausschließlich in diesem Verzeichnis.

Übungsaufgaben sollten jeweils bist zum nächsten PIM-Termin fertig gestellt und hier commited werden.
