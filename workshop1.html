Arbeitsweise Manuell vs. KI

Dieser Workshop ist bewusst in zwei Phasen unterteilt. Ziel ist es, eigene Fähigkeiten im HTML/CSS zu aktivieren und anschließend KI gezielt als Werkzeug zu nutzen und kritisch zu bewerten.

Phase A: Manuelles Arbeiten

  • Erstellen Sie Ihre Seite zunächst ohne KI.
  • Nutzen Sie dafür Ihre bisherigen Kenntnisse, die Vorlesungsfolien und die Dokumentationen der verwendeten Werkzeuge.
  • Ziel ist es, ein grundlegendes Verständnis für Struktur, Inhalte und Aufbau Ihrer Seite zu aktivieren.

Phase B: Arbeiten mit KI

  • Nutzen Sie nun KI gezielt als Unterstützung.
  • Verwenden Sie dafür die Hochschul-KI unter ki.hs-rm.de.
  • Lassen Sie sich z. B. UIkit-Beispiele erklären oder auf Ihr eigenes Thema anpassen.
  • Übernehmen Sie Vorschläge nur dann, wenn Sie verstanden haben, was der Code macht.

1. Html-Basis erstellen

Erstellen Sie eine HTML-Datei index.html in Ihrem vorname-nachname Ordner und füllen Sie diese mit folgenden Inhalten:

  • HTML Basis-Code
  • Eine Hauptüberschrift (z.B. "Mein Basis-Code)")
  • Blindtextelemente (z.B. in <p> oder <section> Elementen)
  • <style>-Block im head oder eine separate CSS-Datei, die Sie in Ihre HTML-Datei einbinden

2. Webfont einbinden

  • Suchen Sie einen oder mehrere Fonts bei Google-Fonts aus.
  • Binden Sie den Webfont in Ihre HTML-Seite bzw. Ihren CSS-Code ein. Google Fonts bietet das passende Code-Snippet dafür an.
  • Passen Sie die Text-Formatierungen für Ihre Überschrift und Blindtext-Elemente grundlegend an. Sie können den Font in Ihrem CSS-Code per font-family: "Name des ausgewählten Fonts", fall-back-font; den gewünschen Elementen zuweisen. Auch diesen Code können Sie sich bei Google Fonts kopieren.

3. UIkit einbinden

  • Binden Sie UIkit ein.
  • Nutzen Sie UIkit in diesem Workshop als Einstiegshilfe: Sie arbeiten mit HTML-Beispielen aus der Dokumentation und passen diese auf Ihre eigenen Inhalte an.
  • Erstellen Sie eine neue Section mit Card-Elementen und befüllen Sie diese mit Beispiel-Inhalten.

4. Bilder einfügen

  • Legen Sie in assets einen Ordner images an.
  • Exportieren Sie Bilder (eigene, KI-generierte oder freie aus dem Netz) mit Photoshop o.ä. in den Formaten .jpg, .png oder .webp in den images-Ordner.
    Hinweis: Maximal 2000 px Breite, 500 kB Größe
  • Binden Sie Bilder in Ihre Seite in UIkit-Cards ein. Nutzen Sie darüber hinaus ein Bild, das Sie der Webseite als Hintergrundbild einfügen. Hierfür können Sie sich auch Bilder generieren lassen, die sich entsprechend kacheln lassen. Wenn Sie Bilder mit KI erzeugen, achten Sie darauf, dass Sie diese vor der Nutzung prüfen und passend für das Web exportieren.

5. Beispieltabelle einfügen und formatieren

  • Befüllen Sie eine Tabelle mit Steckbriefdaten (z.B. Name, Geburtstag, Hobbys, ...).
  • Stylen Sie die Tabelle mit UIkit-Klassen.

Arbeitsweise KI

Führen Sie nun die Schritte 1 bis 5 mit einem LLM (z.B. ki.hs-rm.de) aus bzw. nutzen Sie die KI-Extension in Visual Studio Code.

Benennen Sie die entsprechend generierten Dateien separat (z.B. durch ein _ki am Ende des Dateinamens). Experimentieren Sie gerne, bis Sie Ihr gewünschtes Ergebnis erreicht haben. Wichtig ist, dass Sie Ihr Vorgehen dokumentieren können (s.u.). Dokumentieren Sie beispielsweise Ihre Prompts.

Dokumentation (AI Production Log)

Dokumentieren Sie in einer separaten Textdatei in Ihrer Abgabe kurz Ihre Arbeit mit KI:

  • Welche Prompts haben Sie verwendet?
  • Was hat gut funktioniert?
  • Was war problematisch oder unklar?
  • Was mussten Sie selbst anpassen oder korrigieren?

Auf Validität testen

  • Sorgen Sie dafür, dass Ihre eigenen abgegeben Dateien valide sind. Das betrifft Ihre HTML- und ggf. auch CSS-Dateien.
  • Ihre Dateien können Sie mit dem W3C Web Validator testen.
