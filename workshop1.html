Technologie und Produktion (IM/UI)Workshop 1: HTML/CSS

Herzlich willkommen zum ersten Workshop. In diesem Workshop geht es darum, Grundlagen von HTML (& CSS) zu wiederholen.

Vorlesungsfolien: HTML / CSS
Abgabe: Dienstag, 04. November 2025. Gesamter Ordner als Zip-Datei vorname-nachname.zip auf Stud.IP unter Dateien/Abgaben/ Abgaben – Workshops Technologie und Produktion/Workshop 1

Visual Studio Code installieren

Falls noch nicht gesehen, Installieren Sie

  • Visual Studio Code.
  • die Extension Git Graph.
  • die Extension Live Server.
  • die Extension W3C Web Validator.

Ordnerstruktur

  • Legen Sie den Ordner tup-workshop an.
  • Legen Sie darin einen Ordner mit dem eigenen Namen an mit dem Format vorname-nachname an. Für mich wäre der Name des Ordners beispielsweise johannes-luderschmidt. (Achtung: Keine Umlaute und Sonderzeichen!)
  • Erstellen Sie darin den Ordner assets.

Html-Basis erstellen

Erstellen Sie eine HTML-Datei index.html in Ihrem vorname-nachname Ordner und füllen Sie diese mit folgenden Inhalten:

  • HTML Basis-Code
  • Eine Hauptüberschrift (z.B. "Mein Basis-Code)"
  • Blindtextelemente (z.B. in <p> oder <section> Elementen)
  • <style>-Block im head

Webfont einbinden

  • Suchen Sie einen oder mehrere Fonts bei Google-Fonts aus.
  • Binden Sie den Webfont in Ihre HTML-Seite bzw. Ihren CSS-Code ein. Google Fonts bietet das passende Code-Snippet dafür an.
  • Passen Sie die Text-Formatierungen für Ihre Überschrift und Blindtext-Elemente grundlegend an. Sie können den Font in Ihrem CSS-Code per font-family: "Name des ausgewählten Fonts", fall-back-font; den gewünschen Elementen zuweisen. Auch diesen Code können Sie sich bei Google Fonts kopieren.

UIkit einbinden

  • Binden Sie UIkit ein.
  • Erstellen Sie eine neue Section mit Card-Elementen und befüllen Sie diese mit Beispiel-Inhalten.

Bilder einfügen

  • Legen Sie in assets einen Ordner images an.
  • Exportieren Sie Bilder (eigene, KI-generierte oder freie aus dem Netz) mit Photoshop o.ä. in den Formaten .jpg, .png oder .webp in den images-Ordner.
    Hinweis: Maximal 2000 px Breite, 500 kB Größe
  • Binden Sie Bilder in Ihre Seite in UIkit-Cards ein. Nutzen Sie darüber hinaus ein Bild, das Sie der Webseite als Hintergrundbild einfügen. Hierfür können Sie sich auch Bilder generieren lassen, die sich entsprechend kacheln lassen.

Beispieltabelle einfügen und formatieren

  • Befüllen Sie eine Tabelle mit Steckbriefdaten (z.B. Name, Geburtstag, Hobbys, ...).
  • Stylen Sie die Tabelle mit UIkit-Klassen.

Auf Validität testen

  • Sorgen Sie dafür, dass Ihre eigenen abgegeben Dateien valide sind. Das betrifft Ihre HTML- und ggf. auch CSS-Dateien.
  • Ihre Dateien können Sie mit dem W3C Web Validator testen..
